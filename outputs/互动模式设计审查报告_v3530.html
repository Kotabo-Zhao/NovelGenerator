三、保障机制盘点

3.1 前后连续性（6 层）

L1 前情摘要"开头+结尾双段"（空间尾态不丢，v3.5.21）

L2 大纲章节驱动：每章 2-4 场景，切章自动推进（v3.5.28）

L3 复用小说模式 CharacterStateTracker：场景后提取角色状态写入 global_state（v3.5.22）

L4 复用 LogicSupervisor L1 规则：时间/空间/行为/物品矛盾零成本检查（v3.5.22）

L5 事件时间线（events 8 条）+ facts 承诺硬挂钩（PACT 提取，待兑现回扣）

L6 角色记忆（char_memory）：角色视角记忆，信息不对称

3.2 逻辑性（4 项）

✓ 世界观边界注入（worldbuilding_brief，不得偏离）+ 行动护栏（LLM 结合世界观裁决，v3.5.23）

✓ 角色白名单（场景/对话/行动三处 P0 约束，v3.5.27）——没有召唤的人不出现

✓ 时间只向前、地点变化有过渡、已离开角色不瞬移（SCENE_SYSTEM 规则 11）

✓ 玩家台词过滤全覆盖（场景/行动结果/对话回复，v3.5.27）

3.3 生成质量（5 项）

✓ 场景开头强制环境交代（地点/时间/氛围，v3.5.27）

✓ drift 轨道检测（LLM）+ OOC 抽检（每 10 轮）

✓ 钩子核对（Agenda 推进开关）+ PACT 提取（facts/关系/目标）

✓ AI 检测器离线规则（AI 腔评分）+ 章节回流质量整合（v3.5.29）

✓ 忠实执行模式（v3.5.26）：不加私货，创意增强默认关

3.4 玩家行为理解（实测 10/10）

行动（推门/答应/递茶/签协议/离开）与对话（不同意/闲聊/陈述）判定全部正确；@指定对象正确剥离；长句行动正确识别（v3.5.23 第一人称全覆盖）。

3.5 记忆系统：人物/环境交互的沉淀与回响（实测验证）

写入点（谁沉淀）：

人物交互→记忆 对话（PACT 提取）：承诺/威胁/秘密/告知 → 写入目标角色专属记忆（promise 类，source=pact）；关系变化 → 事件时间线

行动→记忆 行动（apply_action）：关系变化 → 对应角色 attitude 记忆（"读者对你做了行动：…"）；行动本身 → 事件时间线

环境交互→记忆 地点变化 → 全体在场角色写入 event 记忆（"读者去了街角的咖啡店"）+ location 实时更新 + 事件时间线

存储机制（char_memory.py）： 每角色上限 30 条 · 内容级去重（前 30 字相同视为重复）· 信息不对称：角色 A 的记忆 B 看不到（除非剧情传话）· 随互动存档持久化

回响点（谁记得）：

场景生成 注入：待兑现 facts（硬挂钩）· 最近事件时间线 · 角色状态（CharacterStateTracker）· 当前地点——共享剧情状态视角

对话生成 注入：目标角色专属记忆（memory_brief 8 条）——角色视角，"你记得的事你不能装作不知道"

实测闭环（替身的告别，真实 LLM）：

① 行动"去街角的咖啡店" → location 更新 + 事件"读者站起身离开当前地点，前往街角的咖啡店" + 记忆总数 10 条 ✅

② 对话"我答应你，下周一定把设计稿给你" → 记忆 10→11，顾衍之新增"读者答应顾衍之，承诺下周交付设计稿" + facts 更新 ✅

③ 后续场景生成 → 完整记得："街角咖啡店的暖黄灯光从落地窗里漫出来……方才那句'下周交稿'，你说得干脆，可设计稿的内容此刻还只是一团模糊的光影"——地点与承诺不仅被记住，还融入心理描写与剧情 ✅

边界说明： 场景生成注入的是"共享剧情状态"（facts/events/角色状态），角色私密记忆（秘密类）只在对话时注入——符合信息不对称设计（场景中他人不知私密事）。若需场景中角色对私密记忆做出反应，可通过剧情传话实现。

四、本轮审查发现与修复（v3.5.30）

问题严重度说明处理
最后一章永不回流BUG_advance_outline 条件 idx < len-1——最后一章完成时既不切章也不触发章节回流，最后一章内容永远丢失 ✅ 已修：移除限制，末章完成后标记 final_done 防重复；单测 3/3
objective 双写冲突逻辑缺陷PACT 对话后更新 objective（玩家方向），切章又覆盖为大纲摘要——互相覆盖，玩家方向丢失或章节目标丢失 ✅ 已修：切章不再覆盖 objective（大纲章节目标已在场景 prompt 单独注入"当前剧情章节"，两轨并行）
重开/中途退出不回流当前章体验缺陷只在切章时回流——玩家玩到一半重开，本章互动白玩 ✅ 已修：restart 前后台线程回流当前章（不阻塞）
玩家行为理解验证10 类输入实测（移动/承诺/交互/签署/离开/对话/闲聊/陈述/@对象） ✅ 10/10 正确

六、结论

设计初衷：未偏离。 定位（写作管线+对话+语音）、核心闭环（节点对话→状态改写→下一场景）、Galgame 语音体验全部达成，且大纲驱动 + 章节回流使互动成为小说的"可玩版本"，超出原方案。

质量保障：有体系。 连续性 6 层、逻辑性 4 项、质量 5 项检查覆盖；复用小说模式引擎（角色状态/逻辑监督/AI 检测）避免重复造轮子。

玩家行为理解：实测准确。 10/10——行动与对话判定、@对象、长句行动均正确，判断权归 AI、规则仅兜底。

本轮修复 3 个问题（末章回流丢失 / objective 双写冲突 / 重开不回流），均为推进链上的真实缺陷，已修并回归 17/17。

剩余问题均为非阻断优化项，建议按"创建耗时 > rollback 同步 > 验证器误报"顺序处理。
