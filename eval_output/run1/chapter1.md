# 第1章 深夜，屏幕亮起

凌晨两点十七分，陈默灌下第三杯速溶咖啡，删掉第无数行报错的日志代码。屏幕上的数据流像一条死鱼一样翻着白眼，公司号称"新一代智慧物流调度核心"的项目，在他手里已经卡了三天。

他揉了揉干涩的眼睛，把最后一段冗余循环改成位运算，指尖敲下回车。

屏幕突然闪了一下白，像是有人把整间办公室的灯焊进了显示器里，然后一行墨绿色的字从屏幕底部涌上来：【检测到宿主代码适配度98.7%，码神系统绑定中……】陈默愣了一下，手指悬在键盘上没动。

他以为是哪个同事的恶作剧脚本，或者自己加班加出了幻觉。他伸手去摸鼠标，屏幕上的字已经变了：【绑定成功。宿主：陈默。境界：代码学徒（初阶）。

当前功法：《物流调度真经·卷一》】他的目光落在"功法"两个字上，又看了看自己刚写的那段优化代码。

屏幕右下角弹出一个窗口，把他刚才提交的版本号原封不动地列了出来，标注着一行小字："该代码已自动编译为可运行功法，宿主是否选择运转？"陈默把咖啡杯放下，听见自己的心跳声在安静的办公室里格外清楚。

他点了"是"。屏幕上弹出一个新的窗口，像是一份功法图鉴。墨绿色的字迹勾勒出经脉走向，但那些"经脉"分明是他代码里的数据流节点，一条条从入口函数延伸到输出端。陈默盯着看了三十秒，忽然觉得有点荒谬。

他写了三年代码，见过各种离谱的bug，但没见过能把代码画成人体的。他动了动鼠标，想把这个窗口关掉，却发现光标一靠近，那些经脉线条就跟着微微发光。他鬼使神差地把手放回键盘上，敲了一行注释。

奇迹发生了——那行注释没有变成灰色的文本，而是化作一道微弱的光流，顺着经脉图涌进他的指尖。凉丝丝的，像握了一把冰水。陈默猛地缩回手，心脏擂鼓一样撞着胸腔。他站起来，椅子在身后发出刺耳的摩擦声。

办公室里只有他一个人，头顶的日光灯管嗡嗡作响，空调出风口吹出干燥的风。他又坐回去。屏幕上的字还在闪烁：【代码即功法，灵网即道。】陈默的指尖悬在键盘上——他写的这段优化代码，刚刚自动编译成了一门功法。

他盯着那行字看了很久，久到眼睛发酸，才慢慢敲下回车键。窗外，城市的天际线泛着一层灰蓝色的光。黎明快到了。陈默没有关掉那个窗口。他重新看了一遍自己的代码，从第一行到最后一行。

那套被他改了三天的物流调度算法，此刻在屏幕上的投影完全不同了——原本枯燥的if-else嵌套成了经脉的分叉，循环语句是周天运转的轨迹，就连他随手加的异常处理，都变成了功法里标注的"护体罡气"。

他忽然想起自己入行那年，师傅在离职前说过一句话：写代码写到极致，就是在跟机器说话。他当时没听懂，现在依然没懂，但那些经脉图上的节点位置，他太熟了。那是他熬了三个通宵，一个一个调出来的最优路径。

他动了动手指，在键盘上敲下三行新代码。光流再次涌起，比上一次更亮，从指尖一路窜到肘弯，像一条活着的蛇。他盯着自己的手臂，看见皮肤下隐约有什么东西在流动，泛着和屏幕一模一样的墨绿色。

陈默深吸一口气，把那三行代码删了。光流消失了，手臂恢复如常。办公室里只剩下空调的低鸣，和键盘上他指尖残留的一点凉意。他看了眼屏幕右下角的时间：凌晨四点五十二分。距离早会还有三个小时。

他关掉了那个墨绿色的窗口，把代码保存，推上笔记本盖子。屏幕黑下去的瞬间，他看见自己映在屏幕上的脸，眼底有一层没散尽的绿光。他告诉自己那是错觉。

但当他伸手去拿外套时，发现键盘上那行他敲过注释的地方，凹进去一个浅浅的印子——像被什么东西烧过。陈默盯着那个凹痕，拇指摩挲过去，指腹触到一丝余温。不是错觉。

他重新掀开笔记本盖子，屏幕亮起，墨绿色的字迹还在原处，一行行静静地等着他。他坐回椅子上，脊背贴着椅背，忽然觉得自己像站在一扇门前面。门是什么时候出现的，他不知道。

但门缝里透出来的那点光，他刚才已经伸手摸过了——凉的，活的，跟代码有关。他打开编辑器，把那段《物流调度真经·卷一》的经脉图调出来看。节点之间有几处断线，像是一式功法练到中途忽然卡住，真气过不去。

他顺着断线的位置找过去，发现正是他代码里三处他始终不满意的地方，他改了一版又一版，总差临门一脚。陈默敲下一行新的条件判断，补上那个断点。

光流再次涌起，这一次没有散，而是顺着经脉图完整地转了一圈，最后汇入他胸口的位置，温热。屏幕上弹出新的一行字：【《物流调度真经·卷一》运转成功。宿主境界：代码学徒（初阶）→（中阶）。

检测到宿主连续优化时长超48小时，触发隐藏任务：一次不眠的完整调度。】陈默看着"隐藏任务"四个字，又看了眼窗外灰蓝色的天。早会九点开始，他还有四个小时。

他松开键盘，指尖在桌沿敲了两下，然后重新放回按键上。如果这真是门功法，那他要看看，练到底能练出个什么名堂。他敲下第一行代码，把那条断线的起点重新定义。

光流比刚才更快地涌上手臂，这一次他看清了——那些流动的东西不是光，是一行行极细的字符，顺着他的血管排布，像刻在皮肤上的微型代码。陈默停住手，盯着自己的小臂看了很久。

那些字符他认得，正是他昨天删掉的那段废弃代码，一个跑不通的排序算法。它们没有消失，只是换了个地方待着。他忽然意识到一件事。他写过的每一行代码，都在这门"功法"里留下了痕迹。

那些他以为删掉的东西，那些他放弃的方案，那些他加班到凌晨也没解决的死循环——全部被编译进了他的经脉里。屏幕上那行字还在闪。陈默没有关掉它，而是翻开了《物流调度真经·卷一》的最后一页。

页尾有一行小字，他刚才没注意到："注：本功法共九卷，卷一仅为引。宿主当前可见范围，限于自身所写代码总量。若需解锁卷二，须以他人代码为引，运转他山之石。

"他盯着"他人代码"四个字，忽然想起明天早会上，组里那个空降来的技术总监要分享的架构方案。他记得那份方案的文件名，躺在公司共享盘里，标着"绝密"两个字。窗外的天光又亮了一分。

陈默合上笔记本，拇指按在键盘那个凹痕上。他还没决定要不要去看那份文件，但指尖已经在桌沿轻轻敲了两下。那扇门缝里的光，比刚才更亮了一些。
