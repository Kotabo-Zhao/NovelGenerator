# NovelGenerator 微信小程序改造计划

基线报告：[WECHAT_MINIPROGRAM_AUDIT_REPORT_2026-08-11.md](../docs/WECHAT_MINIPROGRAM_AUDIT_REPORT_2026-08-11.md)

## 目标

将当前单用户、本地文件、PWA/Android 复合原型，改造成具备用户隔离、可恢复生成任务和移动端核心闭环的微信小程序产品。

## 阶段

1. **Phase 0：安全冻结**
   - 统一资源 ID 与路径安全校验。
   - 引入认证/授权边界、请求 schema、限流、额度、超时和成本上限。
   - 修复批量检查点、健康检查脚本、依赖清单和 CI 缺口。
2. **Phase 1：后端任务化**
   - 用户/作品/大纲/章节/任务/用量数据模型。
   - 生成、评估、导出统一为持久化 job。
   - 统一 LLM adapter，支持取消、重试、恢复、审计和成本统计。
3. **Phase 2：原生小程序 MVP**
   - 书架、创建、大纲确认、写作/阅读、任务恢复、导出。
   - 4 个主入口：书架、创建、写作、我的。
   - 趋势、小红书、互动、剧情图谱、语音和质量实验室先放入更多功能或后续迁移。
4. **Phase 3：生成质量**
   - 结构化故事圣经、角色状态、事件日志和 token 优先级预算。
   - 合规补写后重新评估，禁止失败占位落盘。
   - 建立离线评测集、人工评分、成本/延迟/质量指标。
5. **Phase 4：高级能力**
   - 互动分支、剧情图谱、语音、趋势/小红书工具、异步导出。

## 完成定义

- 任何作品资源访问都经过认证、owner_id 校验和安全路径解析。
- 同一生成任务可幂等提交，可取消、重试，并在客户端离开后恢复。
- 小程序端不依赖浏览器 DOM、PWA、Service Worker 或 localStorage 认证。
- 大纲、章节、质量报告和导出均有版本/状态/审计记录。
- 真实开发者工具、真机、弱网和并发测试通过；生成质量用固定评测集回归。
