# 网文流派黄金法则研究（v2.3.6 落地）

> 研究日期: 2026-08-01
> 用途: 将各流派头部作品的共性技法提炼为可执行规则，注入 NovelGenerator 章节写作上下文
> 落地模块: `backend/core/genre_playbooks.py`（10 流派 + 通用铁律）
> 注入时机: 每章写作前（普通 + 原子化双路径），约 700 字符

---

## 一、通用铁律（所有流派）

来源：黄金三章理论（平台留存数据验证：前三章留存率 <10% 的书进不了推荐池）、500 本扑街书数据分析、畅销榜前 100 分析。

1. **先给情绪，再给信息；先给冲突，再给设定**——世界观藏进剧情，禁止开篇摆设定
2. **黄金三章分工**：
   - Ch1 冲突种子：前 300 字必须出事（读者耐心 3 秒），主角前 500 字出场
   - Ch2 人设锚点：用行动+台词立人设（"他从地上爬起来，擦掉嘴角的血"≠"他很坚韧"）
   - Ch3 金手指/主线悬念 + 第一个小爽点（金手指必须戏剧性亮相，禁止"叮，绑定成功"）
3. **章末钩子三型**（每章必用）：悬念留白 / 冲突升级 / 爽点预告
4. **每章必须有"变化"**：主角达成至少一个可感知进展
5. **爽点先抑后扬**：情绪爽点（当众羞辱回敬）叠加利益爽点（实质收益）
6. **7-2-1 配比**：70% 主线 / 20% 人设 / 10% 伏笔
7. **细节技法**：身体反应写情绪（紧张→指尖发白；心动→耳尖发烫）、专属小习惯立人设、话里藏话写潜台词
8. **对话禁论文腔**：带情绪、带个性，三角色说话必须可区分

## 二、流派专属法则（10 流派）

| 流派 | 核心卖点 | 关键技法 |
|:---|:---|:---|
| **玄幻修仙** | 升级打脸循环 | 土豆循环（被辱→隐忍→奇遇→升级→打脸→换地图）；越级杀人立威；境界变化可视化；压抑不过三章 |
| **都市爽文** | 王者归来+当众打脸 | 一句话拉满仇恨期待；打脸必须当众+围观者反应；身份马甲递进；仇恨三章内兑现 |
| **宫斗权谋** | 隐忍算计翻盘 | 对话双层（"这花开得好，只是根子不干净"）；隐忍→布局→翻盘；每步一子有后手；规矩细节准确 |
| **甜宠文** | 小事发糖+双标苏点 | 记偏好懂情绪；男主对别人冷对女主特殊；感受优先（体温/心跳）；心理细水长流；发糖绑爽点 |
| **虐爽文** | 信息差拉扯+反转密度 | 读者先知主角后知；先抑后扬火葬场；高密度反转章章钩子；虐要留白 |
| **悬疑文** | 不对劲感+冷静克制 | 越恐怖越不动声色；细节暗示先行；每章 1-2 个线索；双层叙事；情绪走势：日常不对劲→疑云→反转 |
| **系统文** | 金手指期待感 | 绝境戏剧性激活；系统规则自洽；宿主靠性格推动；脑洞 300 字内亮相；奖励节奏 |
| **科幻末世** | 设定钩子+规则冲突 | 核心概念 500 字内亮出；规则即矛盾；生存细节硬核；人性抉择；绝境留微光 |
| **历史文** | 时代质感+大势 | 称谓/官职/物价准确；大历史钩子（读者知道结局他不知道）；谋略分层；配角有立场；爽点在于"势" |
| **灵异文** | 氛围+规则恐怖 | 环境细节造不安；鬼物有明确规则；最恐怖一笔带过；成长阶梯；结尾留大谜 |
| **世情种田** | 真实共鸣 | 白描生活细节；不炫技不升华；情绪积累一击必中；小物件前后呼应；烟火气 |

## 三、匹配规则

`GENRE_RULES` 关键词匹配（genre 字段 → 流派），未命中走"通用"（只有通用铁律）。
示例：`玄幻` → 玄幻修仙、`都市重生` → 都市爽文、`宫斗` → 宫斗权谋、`悬疑推理` → 悬疑文。

## 四、落地方式

```
创建小说（genre 已知）
  ↓
每章写作前 build_playbook_context(genre) → 通用铁律 + 流派法则（~700 字符）
  ↓
追加到 writer context（普通路径 context / 原子路径 chapter_context）
  ↓
LLM 按流派法则写作
```

与已有体系关系：风格系统（40 套预设，管"文风"）+ 流派法则（管"商业技法"）+ 人设卡（管"角色一致性"）+ 一致性校验（管"逻辑"）——四层互补。

## 五、迭代建议

- 每流派可继续深化为"开局模板库"（从爆款书中提取 3 种开局结构）
- 女频细分：甜宠可再拆"校园甜/职场甜/古言甜"
- 流派法则也可用于大纲阶段（卷结构按流派节奏规划）
