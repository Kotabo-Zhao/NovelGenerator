## 二、核心设计：卡片式剧情画布

### 2.1 从"点"升级到"卡片"

现在：每个事件是一个圆点。  
升级后：每个事件是一张 **卡片**（~140×70px），包含：

```
┌────────────── 事件卡片 ──────────────┐
│ Ch5                           P5 🔴 │  ← 章节号 + 优先级
│ 发现真凶线索                          │  ← 事件名称
│ ████████░░ 紧张度 8/10               │  ← 紧张度条
│ 👤主角 👤反派                        │  ← 出场角色图标
│         ● 连线手柄                   │  ← 拖拽创建因果链
└──────────────────────────────────────┘
```

### 2.2 四种连线类型

| 连线 | 含义 | 视觉 |
|:-----|:-----|:-----|
| **因果线** | A 事件导致 B 事件 | 实线+箭头，红色 |
| **分支线** | A 事件引出两个平行走向 | 虚线+分叉，蓝色 |
| **伏笔线** | 此处埋伏 → 彼处回收 | 点线+书签图标 |
| **角色线** | 同一角色出现在多处 | 细线，角色颜色 |

### 2.3 关键交互

**① 拖拽创建分支（Sudowrite 式）**
- 卡片右侧有 "●" 连线手柄
- 拖拽到手柄空白处 → 弹出 "新建关联事件"
- 拖拽到另一个卡片 → 创建因果/伏笔关联

**② 间隙警告（Plottr 式）**  
- 如果某条线程连续 N 章无事件 → 泳道中出现 ⚠️ 标记
- 点击标记 → 弹出 "在此处插入事件？"

**③ 角色叠加模式**
- 工具栏切换 "👤 角色视角"
- 卡片上高亮显示该角色出现的卡片
- 关系线显示为角色之间彩色连线

**④ 右侧检查器面板**
- 点击卡片 → 右侧滑出详情面板
- 显示：完整事件描述、关联伏笔、角色列表、快捷操作按钮
- 不再用底部 tooltip

## 三、视觉升级方案

### 3.1 卡片设计语言

```
阴影: box-shadow: 0 2px 8px rgba(0,0,0,.15), 0 1px 3px rgba(0,0,0,.1)
圆角: border-radius: 8px
背景: 根据线程颜色渐变（左到右）
紧张度条: 卡片底部 3px 彩色条
选中态: ring + glow + 轻微scale
拖拽态: elevation提升 + 旋转1-2°
```

### 3.2 画布背景

不是纯色——用纸张肌理：
```css
background: var(--bg);
background-image: 
  radial-gradient(circle, var(--border) 1px, transparent 1px);
background-size: 24px 24px;
```

### 3.3 动画

| 交互 | 动画 |
|:-----|:-----|
| 卡片出现 | scale(0.9→1) + opacity 0→1, 300ms |
| 拖拽松手 | 吸附到网格 + 弹性回弹, 200ms |
| 创建连线 | 线条从起点画到终点, 400ms |
| 删除 | scale(1→0.8) + opacity 1→0, 200ms |
| 选中 | ring 脉冲 + glow |

## 四、用户操作流程对比

### 现在（简陋版）：
```
1. 进入画布 tab
2. 看到圆点和泳道
3. 拖拽圆点 → 改章节
4. 双击 → 跳转编辑表单
5. 回到画布看效果
```

### 升级后：
```
1. 进入画布 tab — 看到卡片网格
2. 点击卡片 → 右侧面板显示详情
3. 拖拽卡片 → 重新排序（同泳道内）
4. 拖拽连线手柄 → 创建因果/分支
5. 右键空白 → "新增事件" → 输入一句话 → 卡片出现
6. 切换 "👤 角色视角" → 看到角色关系线
7. 发现 ⚠️ 间隙警告 → 点击 → 插入事件
8. 全部操作在画布上完成，0次切换tab
```

## 五、实施计划

### Phase 1: 卡片化（2h）
- 替换 SVG 圆点为 DOM 卡片
- 卡片渲染（名称、紧张度条、章节号、角色图标）
- 拖拽移动（吸附到章节网格）
- 紧张度调节（垂直拖拽或卡片内滑条）

### Phase 2: 连线系统（2h）
- 因果连线渲染（SVG overlay 贝塞尔曲线）
- 连线手柄交互（拖拽创建）
- 分支线视觉（虚线+分叉）
- 伏笔线（书签图标+虚线）

### Phase 3: 智能特性（1.5h）
- 间隙警告（⚠️ 标记 + 一键插入）
- 角色叠加模式（角色筛选高亮）
- 右侧检查器面板（替换 tooltip）
- 撤销/重做（Ctrl+Z）

### Phase 4: 打磨（1h）
- 卡片动画（出现/吸附/删除）
- 纸张肌理背景
- 小地图（右下角缩略图）
- 快捷键（Space+拖拽=平移, Delete=删除选中）
