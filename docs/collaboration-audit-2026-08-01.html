⚠️ 断点 1：预算保护与注入段顺序

预算截断发生在 build_writer_context 内部（9000 字符线），而 🎭🎙📕🧭 四个注入段是在截断之后追加的——当前 Ch2 实测 8650 未超线，但长篇小说后期（章节摘要累积）可能把总长推到 9000+，注入段不受预算保护。建议：把预算检查移到完整组装后，或给注入段设独立上限。

5断点与风险清单

诚实清单：3 个真实断点 + 4 个依赖风险。

🔴 断点

  • 1. 旧书补全无前端入口：generate-all API 已上线（港漫已跑），但前端无按钮——旧书用户无法自助触发
  • 2. 预算保护不覆盖注入段：9000 字符截断在 🎭🎙📕🧭 追加之前，长文后期总长可能超限
  • 3. 声音卡/人设无展示页：bible 已"变厚"但前端角色 Tab 只显示图谱快照，蒸馏成果用户看不到全貌

🟡 依赖风险

  • CharacterStateTracker 提取质量：永久状态账本依赖 LLM 提取，无监控（AUDIT P1-4 遗留）
  • 原子化 vs 普通双轨：两套生成路径仍并存，调参/校验双份维护
  • 本地代理依赖：git 走 7890 代理，代理未运行即 push 失败（已多次踩坑）
  • 前端无构建链：单文件 22 万字符，改动风险集中（本轮已三次全量替换）
