# Android 4.0.3 — 小说世界恢复与重构

来源：DeepSeek 本地 `NovelGenerator-miniprogram` 工作区，分支 `feature/miniprogram-phase0`。

在 4.0.2 的底栏、模型设置、原版 SillyTavern 角色扮演修复基础上，恢复原小说世界引擎与群像场景页。通过底栏「入世」选择作品，再选择主角、配角或反派身份进入剧情。对话、行动、状态、自动存档、回退、重开沿用书中世界；正式小说章节保持独立，手动导出写入独立目录。

本次重构：

- 将场景页样式、应用逻辑、流处理拆分为独立资源，复用主应用的请求与 SSE 读取器。
- 流事件合并刷新；重写重复场景时清空预览；模型内容对象不再强转为异常字符串。
- 长记录默认渲染最近 80 条，可展开更早记录；进入和同步资料时不读取全部章节正文。
- 同一本书的写作与世界操作互斥，锁覆盖整个 SSE；存档读写隔离可变对象并记录版本；过期后台提取不得覆盖新进度。
- 规则检查合并为原子更新；过期场景检查与重复任务跳过；保留损坏存档副本。
- 修复空存档重开后无法选身份、底栏遮挡确认按钮、行动面板与输入区域重叠。

验证：97 项 Python 回归通过；最后清理后相关 9 项再次通过；公共前端运行时 24 项通过；新增流重试、Unicode、对象内容、终止事件、异常、历史窗口检查通过。隔离小说和本地 mock 模型验证了多角色开场、对话、行动 SSE、进度恢复和重复剧情保护。浏览器在 360 / 390 像素宽度检查了底栏和输入框，未发现 JavaScript 错误。

交付：`dist/NovelGenerator-v4.0.3-miniprogram-arm64-debug.apk`，版本号 68，Android 8.0+，ARM64，debug 内部版。使用与 4.0.2 相同的 debug 签名。最终 SHA256、资源对照和构建记录见 `dist/novel-world-20261020/build-receipt.json`。
