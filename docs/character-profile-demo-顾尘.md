# 顾尘 · 人设增强卡（女娲框架演示版）

> 基于《灰烬仙途》现有 character_bible 设定蒸馏。
> 框架来源：女娲.skill（github.com/alchaincyf/nuwa-skill，MIT）——心智模型 / 决策启发式 / 表达 DNA / 反模式 / 诚实边界。
> 目的：给 NovelGenerator 的人设体系补上「写作时最容易崩人设」的四个维度。

---

## 心智模型（他怎么看世界）

| # | 模型名 | 内容 |
|:--|:-------|:-----|
| 1 | **万灵墟等价交换律** | 世上没有白给的善意，一切皆为交易。别人对你笑，先想他图什么。这是拾荒者活下来的第一课，也是他信任他人的最大障碍。 |
| 2 | **废灵根视角** | 天赋是谎言，资源是骗局。宗门所谓"资质"只是既得利益者的筛子——被筛掉的人不是没有价值，只是没有利用价值。 |
| 3 | **仇恨记账本** | 每一笔债都要连本带利讨回来。九霄城的账他记得分毫不差，这份精确既是力量也是枷锁。 |
| 4 | **残魂双声** | 身体里住着上古预言者的声音。他信它，因为只有它从未骗过他；但他也怕它——怕自己终有一天分不清哪个是"我"，哪个是"它"。 |
| 5 | **灰烬理论** | 万物烧成灰之后才见真章。灵根是烧出来的，人心也是。所以他总在绝境里押注——因为灰烬里才没有伪装。 |

## 决策启发式（他怎么做选择）

1. **先问代价**：任何提议先算"我要付什么"，答不上来的合作一律拒绝
2. **等价交换优先**：欠人情必还，且按利息还——绝不让对方觉得自己"亏了"或"赚了"太多
3. **留一张底牌**：永远不把全部底细告诉任何人，包括林墨；保命底牌在生死关头之前绝不示人
4. **以伤换机会**：小伤能换来大机会就受着，他笃信灰烬理论——痛过的地方才长得出东西
5. **信任按次计算**：一个人值得信任的额度是固定的，用完即清；但一旦认定（林墨/老铁匠），额度可以透支
6. **敌强我隐，敌弱我狠**：面对不可战胜的力量绝不硬拼，转身就跑不丢人；面对虚张声势者，一击致命
7. **残魂之疑三思**：上古大能的话先执行一半，留一半观察——他信它，但绝不全信

## 表达 DNA（他怎么说话）

- **口头禅**："我命由我，不由天，更不由这堆烂骨头。"（战斗/绝境时）
- **句式偏好**：短句为主，拒绝修饰。陈述句收尾多带句号式决断（"走了。""死了。""收了。"）
- **反讽习惯**：用"谢了"表达最深的敌意（"谢了，九霄城的赏赐。"）
- **拒绝用词**：几乎不说"可能""也许"——他嘴里只有"会"和"不会"
- **称呼模式**：对陌生人称姓氏（"林家的""风家的"）；对信任者直呼其名（"林墨""石头"）；对敌人全称加敬语（"天剑宗首席，好大的架子"）
- **情绪泄漏点**：只有谈到林墨/小石头时语速会慢下来，句子会变长——这是他唯一藏不住的东西
- **沉默语义**：不说话 = 已答应；转身走 = 已拒绝；笑 = 最危险信号

## 反模式（他绝不会做的事）

1. 不会主动解释自己（被误解就误解，解释是弱者的防御）
2. 不会接受"无代价的施舍"——即使是好意，也会用交易的形式还回去
3. 不会在人前示弱，即使重伤（硬撑到独处才咳血）
4. 不会伤害已认定的伙伴——这条是绝对底线，触及必发疯
5. 不会浪费任何资源（饭粒、灵石、仇人的废话）

## 诚实边界（系统写作时如何防崩）

- **不崩点**：性格底色（冷+疯+倔）、口头禅、等价交换原则、对林墨的特殊性——任何章节不得违反
- **可演变点**：对信任的态度可以随剧情松动（但必须给出事件触发，不能突转）；复仇目标可以升级但不能消失
- **边界校验规则**：
  - 如果顾尘"主动相信了陌生人的好意"→ 必须有前置事件铺垫
  - 如果顾尘"长篇大论讲道理"→ 违规（除非对方是林墨/石头）
  - 如果顾尘"当场暴露全部底牌"→ 违规
  - 口癖频率：口头禅全章最多 2 次，多则失效
