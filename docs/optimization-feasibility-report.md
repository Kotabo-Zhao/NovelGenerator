## 四、建议立即执行的 Top 3

### 1. 集成 evaluation_system → 质量门（1h）

当前质量门用简单关键词（反转/打脸/冲突）和正则统计。`evaluation_system.py` 已有：
- `hook_strength()` — 章末钩子强度分析
- `dopamine_density()` — 爽点密度量化
- `sentence_fragmentation()` — 碎片化检测
- `evaluate_chapter()` — 综合评分

改为：质量门调用这些函数，输出 0-100 分 + 具体问题定位。

### 2. 上下文智能裁剪（2h）

当前 `_build_writer_context` 把上一章最后2000字 + 前几章摘要全部塞给 LLM。长篇小说后期 context 过长。

改为：
- 上一章：取最后 800 字（而非 2000）
- 更早章节：只保留最近 2 章摘要（而非 3 章）
- 新增：**本章相关剧情线注入**（只注与本章角色/冲突相关的线程）
- 新增：**token 预算硬限制**（总 context ≤ 4000 tokens）

### 3. 批量生成断点续传（2h）

当前批量生成中断后所有进度丢失。改为：
- 每章完成后立即更新 state.json
- 中断后下次点批量生成 → 自动从断点续传
- 前端显示 "已完成 5/10，从第6章继续"

## 五、总结

今日已完成大量工作（剧情图谱可视化、卡片画布、编辑器、快餐模式、方向盘等），系统已从"能生成"进化到"能控制"。接下来的优化方向应该是**稳定性**和**智能化**——让系统不仅能跑，还能跑得好、跑得稳。

建议先做 Top 3，预计总投入 5 小时，覆盖最痛的三个点。
