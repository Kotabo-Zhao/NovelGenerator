# 剧情图谱编辑器 — 使用指南

> NovelGenerator v2.7 | 2026-07-25

---

## 核心理念：两个阶段，两种编辑方式

编辑器的设计哲学是**前期自由搭建，后期精确微调**。

```
┌──────────────┐         ┌──────────────┐
│  大纲阶段     │  ────→  │  写作阶段     │
│  (自由编辑)   │  确认大纲 │  (结构锁定)   │
└──────────────┘         └──────────────┘
  ✅ 增删剧情线             🔒 结构不可变
  ✅ 调整章节结构            ✅ 自然语言微调
  ✅ 修改伏笔回收时间        ✅ 紧张度调整
  ✅ 画布自由拖拽            ✅ 角色状态更新
  🎨 完整编辑权限            📖 画布只读查看
```

---

## 一、大纲阶段（生成大纲后、开始写作前）

### 你在这一阶段做什么

这是你**搭建故事骨架**的唯一窗口。一旦点"确认大纲"，结构就锁定了。

### 可用功能

#### 📋 剧情线编辑
- **新增剧情线**：工具栏 `+ 新增` 按钮
- **调整优先级**：`⬆️` `⬇️` 或拖拽滑条（P1最低，P5最高）
- **修改状态**：`⏸️暂停` / `✅完结` 或在编辑表单中改
- **详细编辑**：`✏️` 按钮 → 修改名称、描述、紧张度、下一步计划、关联角色
- **删除**：表单中的 `🗑️` 按钮

#### 📌 伏笔编辑
- **新增伏笔**：工具栏 `+ 新增` → 输入描述和计划回收章节
- **调整回收时间**：`⏪推迟5章` 或编辑表单修改
- **手动回收**：`✅回收`
- **编辑详情**：`✏️` 按钮

#### 👤 角色编辑
- **编辑角色状态**：每个角色卡右上角 `✏️` →
  - 改位置 "沈清许现在在暗影殿地牢"
  - 改情绪 "她开始愤怒了"
  - 改目标 "她决定越狱"
  - 加/删异常状态

#### 🎨 画布
- **拖拽事件卡片** → 改变事件发生的章节（左右拖）和紧张度（上下拖）
- **右键卡片** → 升温/降温/新增事件/删除
- **⚠️ 间隙警告** → 线程超过5章无进展自动标红，点击即添加事件
- **缩放/平移** → 滚轮缩放，拖拽空白区平移

### 关键操作：确认大纲

当你觉得故事结构已经满意了，点击顶部 **✅ 确认大纲，锁定结构**。

此操作后：
- ✅ 不能新增/删除剧情线
- ✅ 不能新增/删除伏笔
- ✅ 不能移动事件到不同章节  
- ✅ 只能通过**自然语言方向盘**进行微调

## 二、写作阶段（开始生成章节后）

### 你在这一阶段做什么

故事大结构已锁定。现在你是**导演**，不是**编剧**——你控制的是每场戏的力度、情绪、节奏，而不是故事走向。

### 🎛️ 方向盘面板（核心工具）

输入自然语言指令，系统自动解析执行：

| 想做什么 | 输入 |
|:--------|:-----|
| 让某条线升温 | "让复仇主线升温" |
| 暂停某条线 | "暂停感情线" |
| 调优先级 | "复仇主线优先级提到最高" |
| 推迟伏笔 | "把玉佩秘密推迟到25章回收" |
| 回收伏笔 | "回收大师兄身份" |
| 改角色位置 | "沈清许现在在暗影殿地牢" |
| 改角色情绪 | "主角开始愤怒了" |

### 快捷按钮

每条线程保留精简按钮：
- `🔥升温` `⏸️暂停` `▶️恢复` — 节奏控制
- `⬆️` `⬇️` — 微调优先级

### 不可用的功能（结构已锁定）

- ❌ 新增/删除剧情线
- ❌ 新增/删除伏笔  
- ❌ 新增/删除事件节点
- ❌ 移动事件到不同章节
- ❌ 修改剧情线名称、类型

## 三、快餐模式 🍔

勾选快餐模式后，整个系统切换到爆款网文节奏：

| 参数 | 标准模式 | 快餐模式 |
|:-----|:-------|:-------|
| 章节字数 | 3000字 | **2500字** |
| 爽点密度 | 600字/个 | **300字/个** |
| 前300字 | 有冲突 | **直接炸（身份暴露/打脸）** |
| 对话 | ≤4轮 | **≤3轮必须打断** |
| 章末 | 有悬念 | **金句钩子（可截图）** |
| 环境描写 | ≤2处 | **0（冲突场景除外）** |
| 心理描写 | 少 | **0（全动作表达）** |
| 质量门 | score<60重试 | **门槛更高（12项检查）** |

快餐模式必须**在大纲阶段勾选**，创建小说后不可更改。

## 四、典型工作流

```
1. 创建小说（勾选🍔快餐模式）
        ↓
2. 查看大纲 → 进入剧情图谱
        ↓
3. 【大纲阶段 — 自由编辑】
   - 在剧情线tab加一条暗线
   - 在画布上拖拽调整事件顺序
   - 调整主线优先级到P5
   - 推迟一个伏笔的回收时间
        ↓
4. 点击 ✅ 确认大纲，锁定结构
        ↓
5. 【写作阶段 — 方向盘微调】
   - 生成第1章
   - 感觉节奏不够猛 → 方向盘输入"让主线升温"
   - 生成第2章
   - 觉得伏笔该收了 → "回收玉佩秘密"
   - 生成第3章
   - 角色该换地点了 → "沈清许现在在暗影殿地牢"
        ↓
6. 批量生成 → 方向盘持续微调 → 完结
```
